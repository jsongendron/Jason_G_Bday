STAGE 00.

INTRODUCTION.

This style guide defines the visual language for data visualisation and reporting. The palette is grounded in nature — deep forest greens, worn sage, the gold of a dry field in late afternoon. Colour is used deliberately and sparingly. The data insight, not the design, is the hero.

STAGE 04.

GRADIENTS.

Use gradients sparingly — primarily for hero sections or special emphasis. All gradients maintain low saturation and subtle transitions. Avoid using gradients in data visualisations.

PRIMARY GRADIENT
Forest to harvest gold. Use for headers or hero sections.
linear-gradient(135deg, #3D6E50 0%, #C8A84B 100%)
SUBTLE GRADIENT
Parchment to dusty lavender. Use for subtle depth on backgrounds.
linear-gradient(135deg, #F5F7F2 0%, #EBE4F5 100%)
FADE GRADIENT
Transparent to parchment. Use for content fade effects.
linear-gradient(to bottom, rgba(245,247,242,0) 0%, #F5F7F2 100%)
ACCENT GRADIENT
Deep canopy to meadow. Use very sparingly for special callouts.
linear-gradient(135deg, #1A2E22 0%, #5A9B72 100%)

STAGE 06.

USAGE GUIDELINES.

Restraint is the core principle. Less is always more. These guidelines ensure consistency across all applications while maintaining the minimalist philosophy.

▶ DO
  • Use generous white space
  • Limit colour use to 2–3 per design
  • Let deep canopy do most of the heavy lifting
  • Use harvest gold sparingly for emphasis
  • Maintain clean hierarchy through size
  • Use functional colours only for data states
  • Keep backgrounds predominantly parchment
  • Trust typography over decoration
▶ DON'T
  • Use all colours in a single design
  • Apply gradients to data visualisations
  • Use functional colours decoratively
  • Over-saturate or brighten the palette
  • Add drop shadows or heavy effects
  • Use bright, primary colours
  • Clutter layouts with unnecessary elements
  • Mix this palette with other brand colours

▶ CHART RECOMMENDATIONS
  • Use forest green as primary data colour
  • Apply harvest gold for comparative series
  • Keep backgrounds parchment or pure white
  • Use minimal gridlines (pale sage colour)
  • Remove chart borders when possible
  • Use deep canopy for all text and labels
▶ KPI CARDS
  • White cards on parchment background
  • Primary metric in harvest gold or deep canopy
  • Comparison metrics use functional colours
  • Minimal borders (pale sage, 1px)
  • Generous padding (32–48px)
  • Use caption style for labels
